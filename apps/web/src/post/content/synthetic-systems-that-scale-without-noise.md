## Tokens before components

Name each color by its role, not by its hue. A component then asks for a role, and a theme answers it.

```css
.button {
  background: var(--primary);
  color: var(--primary-fg);
}
```

## Roles at a glance

| Role    | Use it for                  |
| :------ | :-------------------------- |
| primary | The one main action         |
| danger  | Actions you cannot undo     |
| muted   | Text that supports the rest |

A system that grows by adding roles stays calm. A system that grows by adding hues gets loud.
