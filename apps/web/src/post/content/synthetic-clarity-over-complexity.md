## One accent voice

A restrained interface uses **one** accent color for the action that matters. Everything else stays quiet, so the eye finds the action first.

- Keep status colors for status.
- Keep the accent for the primary action.
- Let type and space do the rest.

## Scan paths

People scan in a predictable order. A clear hierarchy makes that order match the content order.

> A page that asks for attention everywhere gets it nowhere.
